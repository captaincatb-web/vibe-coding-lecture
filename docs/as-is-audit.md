# 현황 진단
기준·관측 한계는 [현재 구조](architecture-as-is.md) 참조. 운영 페이지가 아닌 로컬 소스 검사 결과다.

## 전수 재현
`node scripts/audit-silicon-library-v2.js`는 45개 기업·13개 공정·31개 기술 각각의 길이(JSON 직렬화 문자 수), 연결, 누락된 절, 기업별 사실 건수 및 정량 텍스트 검토 후보를 JSON으로 출력한다.
이는 설명의 질이나 정량 주장의 진실을 자동 판정하지 않는다. 네트워크 URL 접근 검사도 별도이며, 출처 참조 ID 무결성과 구분한다.

| 항목 | 실측 |
|---|---:|
| 책 행 / 기업 레코드 / ref 행 | 46 / 45 / 1 |
| 공정 / 제품 기술 / 출처 레지스트리 | 13 / 31 / 188 |
| 자료 확보 등급 A/B/C | 30 / 13 / 2 |
| 사실 표 등록 / 검증 / 부분 / 미검증 | 15 / 7 / 6 / 2 |
| 사실 표 있는 기업 / 없는 기업 | 3 / 42 |

기존 사실 표의 검증 상태를 보존한 값이다. 이번 작업에서 7건의 원문을 다시 검증했다는 뜻이 아니다.

## 우선순위
1. P0 계측·검사(metro): 제품 0, 회사 연결 0. 회사가 존재하지 않는다는 의미가 아닌 수록·연결 공백으로 안내한다.
2. P0 자료 확보 A/B/C와 사실 검증 상태 분리 유지. 발행일 미기재 f001/f002/f003/f021, 신뢰도 변경 검토 10건 및 C등급 2건.
3. P1 clean: 웨이퍼 세정과 부품 세정이 같은 연결 축에 있다. ID를 바꾸기 전에 사용 범위·제품별 관계를 명시한다.
4. P1 증착 장비·본딩·언더필·몰딩 연결 부족. PR #3 심화 콘텐츠와 비교한 뒤 D에서 추가한다. 후보 기업·거래관계를 추정으로 채우지 않는다.
5. P1 42개 기업의 문장별 대조, 기존 수치의 발행일/범위/단위 분리. 188개 출처 URL의 현행 접근성과 라이선스는 재검증 전이다.

## 검증
데이터 검사: 오류 0·경고 0·검토 12·참고 30. 부정 테스트: 원본 포함 15/15.
UI 최초 시도는 기본 Playwright 브라우저 경로 부재, 다음 시도는 관리형 Chromium의 file:// 차단으로 실행 실패했다.
HTTP 서버와 /usr/bin/chromium으로 실행한 원본 UI 결과 및 개선 후 결과는 [검증 기록](validation.md)에 기록한다.
Google Fonts 접근 실패는 환경 리소스 오류로 따로 남긴다. 시스템 폰트 fixture 모드는 외부 글꼴 접근을 검증하지 않는다.
