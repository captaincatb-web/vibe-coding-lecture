# 학습 이어가기

`#learn`에서 입문·실무·심화·산업의 4개 경로를 따라 읽고, 마친 단계의 완료 칸을 직접 표시합니다. 총 16단계이며, 다시 선택하면 완료를 취소할 수 있습니다. 링크를 방문하거나 퀴즈에 정답을 고르는 것만으로 단계가 완료되지는 않습니다.

실습의 퀴즈 선택은 같은 브라우저에서 다음 방문에 복원됩니다. 학습 경로의 퀴즈 정답 수는 저장된 선택과 현재 문제의 정답을 비교해 계산하며, 완료 진행률과 별도로 표시합니다.

실습 설정을 조작하거나 퀴즈를 선택하면 마지막 실습 주소를 저장합니다. `#learn`의 **마지막 실습 이어가기**로 돌아가면 설정과 반응 단계가 복원됩니다. 다른 사람이 공유한 실습 주소를 열 때는 그 주소의 설정이 적용됩니다. 단순 방문은 이전에 저장한 실습 주소를 덮어쓰지 않습니다. **초기값으로 재설정**은 마지막 실습 설정도 초기값으로 바꿉니다. 퀴즈 선택은 그대로 유지합니다.

기록은 `siliconLibrary:study:v1` 키로 현재 브라우저의 로컬 저장소에 보관됩니다. 다른 기기와 동기화하지 않으며, 사이트 데이터 삭제 시 지워집니다. 기존 즐겨찾기·탐색 책갈피·최근 본 항목·색상 설정은 별도 키를 유지합니다. 탐색 책갈피 백업 파일에는 학습 기록이 포함되지 않습니다.

저장소가 차단되거나 용량이 부족하면 저장 실패를 화면에 알립니다. 완료 칸은 이전 상태로 돌아가고 진행률은 증가하지 않습니다. 실습 계산과 퀴즈 해설은 계속 이용할 수 있으며, 저장되지 않은 답안임을 표시합니다. 손상되거나 알 수 없는 버전의 기록은 빈 상태로 읽고, 알려지지 않은 단계·실습·답안·외부 이어가기 주소는 제외합니다.

검증은 `npm run check`와 `npm run test:study`로 실행합니다. 브라우저 검증은 Python HTTP 서버가 실행 중이어야 합니다. `SL_TEST_URL`로 테스트 대상 경로를 지정할 수 있습니다.

이번 수정에는 잘못된 실습 식별자의 안전한 처리, 키보드 탭 이동 후 제목 포커스 유지, 공정 단계 취소 후 이전 오류 안내 제거도 포함합니다. 해당 회귀 검증은 `npm run test:labs`에 있습니다.
