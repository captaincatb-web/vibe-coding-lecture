# 실리콘 서재 2.0 — 탐색과 학습의 연결

기준: 2026-11-08 KST. 검토 브랜치 `codex/silicon-library-v2-explorer`.

## 사용자 흐름

책장을 보존하고 공통 내비게이션에 통합 탐색·학습 랩·학습 경로를 더했다. 책에서 해당 기업의 연결 탐색으로 바로 이동할 수 있다. 새 본문 건너뛰기와 main 영역, 수동 색상 모드·시스템 다크 모드를 지원한다.

- **ALD:** 검색 → 전구체 또는 증착 심화 → 연결 제품/공정/기업 → 기존 사실 기록·자료 링크. 한글·영문·약어·띄어쓰기와 전각 영문을 처리한다.
- **HBM:** 검색 → 범핑·TSV·HBM → 연결 품목·심화 해설 → 기존 원문 출처. 적층 구조 랩에서 층·TSV·연결부·언더필·기판·열 흐름을 분리해 본다.
- **기업:** 기업 검색 → 제품 → 공정 → 관련 심화 설명과 자료. 카탈로그 연결을 특정 고객 납품으로 표시하지 않는다.
- **개인 탐색:** URL에 검색어·필터·선택 항목을 담아 공유한다. typed ID를 사용하는 탐색 책갈피와 최근 12개 항목을 로컬 저장하며 기존 책장 즐겨찾기는 보존한다. 선택 항목 인쇄를 지원한다.
- **기업 비교:** 선택한 기업 항목에서 최대 3곳을 비교한다. 주/보조 분류·자료 확보 등급·공급망 판단 근거·사업/법인 단위·품목·공정·기존 사실 대조를 나란히 보여준다. 국가·공시 미수록은 미확인/미수록으로 남기고 숫자 0이나 추정 정보로 채우지 않는다. 비교 선택은 URL에 포함된다. 세부 변경과 검증은 [추가 개선 기록](comparison-improvements.md)을 참조한다.

`#explore`는 94개 정규 항목(기업 45·기술 31·공정 13·심화 5)을 검색한다. 데이터는 화면 진입 시 한 번 로드하며 로딩 실패 시 기존 내비게이션과 재시도 경로를 유지한다. 출처 재확인 상태와 과거 사실 대조 상태를 구별한다. 검색 결과에는 본문과 연결 항목의 제목·별칭도 포함한다.

## 교육용 모델

| 랩 | 조작 | 계산·표현 |
|---|---|---|
| 노광 | 파장 예시·NA·k1 | Rayleigh CD 관계, EUV 예시의 NA 상한과 액침 조건 명시 |
| ALD | 사이클·가정한 GPC·반응 단계 | 선형 막 두께, 전구체/퍼지/반응가스/퍼지, 원자 1층 단순화 배제 |
| CMP | 상대 압력·속도·시간·계수 | 정규화한 Preston 상대 제거량, 실제 nm/min 예측 금지 |
| 공정 시퀀스 | 단계 추가·취소 | 단순 패턴 전사 상태와 단면, 제한된 교육 순서·최대 24단계 |
| HBM 구조 | 층 수·분리·회전·가시성 | SVG 개념 투영도; 실제 제품 치수나 지원 다이 구성이 아님 |

각 랩은 목표·즉시 결과·수식·단위·가정·적용 한계·원문 참고 링크·퀴즈와 재설정을 제공한다. 네이티브 폼 컨트롤로 키보드·터치를 지원하고 WebGL 없이 SVG로 동작한다. 교육용 변수 범위는 장비 사양이나 양산 레시피가 아니다. 참고 URL은 이번 작업에서 원문 재열람을 완료한 것으로 표시하지 않는다.
`#learn`은 입문/실무/심화/산업의 4단계 경로와 14개 용어의 정의·약어·상세 연결을 제공한다.

## 통합과 데이터 경계

PR-B의 head 89f17a6 위에 PR #3 head abc28ea981f0ec428545458761b9e32dbad69be5를 검토 브랜치에서만 로컬 통합했다(ccbb2b4). renderProc 충돌에서 PR #3 noteBox/LINKNOTE/심화·정량 상태와 A의 빈 상태 안내를 함께 보존했다. DEEP JSON과 원본 export 전체가 #3과 JSON 기준 동일함을 확인했다.
정규화 자료는 기업 45·공정 13·제품 31·사실 15·출처 224·심화 5개다. 법인 수나 확인된 공급 관계 수로 과장하지 않는다. 검색 인덱스는 legacy_snapshot을 제외하고 관계·검색 텍스트·필요한 참고자료를 정적으로 생성한다.
생성 명령은 `npm run build`, 전체 데이터·모델 검사는 `npm run check`다. 생성본 최신성은 CI에서도 검사한다. 브라우저에서 키나 공시 API를 호출하지 않는다. 모델/시각화/문구는 직접 구현했으며 외부 교육 사이트의 코드나 그림을 복제하지 않았다.

## 아직 필요한 외부 확인

- PR #3·#4는 재조회 시 OPEN이며 운영 후보 브랜치·기본 브랜치를 병합하지 않았다. 이 통합 브랜치는 검토용이고 이미 운영에 적용된 버전이 아니다.

- 클라우드에는 api.github.com/운영 Pages/Google Fonts 접근에 필요한 허용 도메인 4개를 설정 초안에 저장했다. 초안 저장은 실행 환경 적용·환경 게시·사이트 배포와 서로 다르다.
- Sangsaengnews 비공개·암호화 자료는 수집하지 않았다. 국가·법인 범위가 미확인인 항목에 국가 필터나 지도 위치를 추정으로 넣지 않았다.
