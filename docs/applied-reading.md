# 지표·가상 데이터·종합 사례로 읽기

2026.11.10 편집. 45개 회사별 해설에 이어 품목과 교과서의 적용 학습을 세 차례로 보강했다. 기업의 제품 사양·고객 채택·양산 성능을 새로 주장하지 않는다.

## 1차: 품목 자료를 비교하는 기준

31개 품목에 서로 다른 평가 축 93개와 가정 사례 31개를 작성했다. 각 축은 ‘무엇을 보는가’와 ‘함께 맞출 조건’을 나누며, 사례는 관측·두 가지 원인 후보·비교할 자료·해석 범위로 구성한다.

대표적인 구분은 원료 분석과 실제 박막, 선택비와 누적 보호층 손실, 평균 CMP 제거량과 국부 형상, 접촉 저항과 고속 신호, 무부하 도달압력과 공정 부하 배기, 비저항과 입자, 장치 속도와 전체 이송 시간이다. 모든 품목의 본문은 책장·통합 탐색 검색에 포함된다. 회사 책에서는 기존 ‘품목 공통 원리’를 펼쳐 같은 내용을 읽는다.

자료가 없는 와이컴·GT를 일반 원리로 검증된 제품 업체처럼 표시하지 않는다. AMMK의 실제 PTFE 사업과 HBM 적용 추정도 기존 구분을 유지한다.

## 2차: 교과서의 계산과 종합 사례

11종 교과서의 기존 3개 장 뒤에 계산 장과 종합 사례 장을 추가했다. 현재 총 55개 장·핵심 용어 66개다. 각 계산에는 가상 입력·가정·단위·수식·과정·결론·한계가 함께 표시된다.

| 교과서 | 계산으로 확인하는 질문 | 가정하에서 얻는 결과 |
| --- | --- | --- |
| 산업 | 사업부·법인의 내부 구성과 시장점유율은 같은가 | 25%, 12.5%는 서로 다른 분모·분자의 구성 비율 |
| 박막 | 초기 성장이 다르면 같은 반복 횟수의 막도 같은가 | 20 nm와 18.4 nm |
| 플라즈마 | 퍼센트포인트와 상대 감소는 같은 표현인가 | 3퍼센트포인트 감소, 60% 상대 감소 |
| 식각 | 선택비가 같으면 총 보호층 손실도 같은가 | 시간 증가에 따라 6 nm에서 7.5 nm |
| 노광 | 해상도 척도와 초점 심도는 같은 비로 변하는가 | 0.8배와 0.64배 |
| CMP | 평균 두께가 같으면 국부 두께도 같은가 | 평균 850 nm, 세 점 범위 60 nm |
| 제조 흐름 | 단계 수율의 평균이 전체 통과 비율인가 | 조건부 비율의 곱, 약 94.11% |
| 패키징 | 다이 상태와 조립 통과는 같은 조건인가 | 독립 다이 모델에 조립 조건을 붙이면 약 90.43% |
| 테스트 | 불합격품은 모두 실제 불량인가 | 불합격 중 실제 불량 약 47.62% |
| 메모리 | 비트·바이트와 이론·유효 대역폭은 같은가 | 이론 128 GB/s, 가정한 유효 102.4 GB/s |
| 팹 운영 | 이동 시간이 절반이면 전체 시간도 절반인가 | 다른 시간이 고정된 모델에서 100초 → 85초 |

위 결과는 실제 제품의 표준값이나 회사 성능이 아니다. 종합 사례에서는 근거 연결, 원료·평면·깊은 구조 자료, 챔버의 시간·위치 변화, 로딩과 종횡비, 선폭과 오버레이, 결함 분류, 측정 불확실성, 열·계면·변형, 재시험, 작업의 메모리 접근, 사용 지점·운영 경계를 다룬다.

교과서 서가의 ‘가상 데이터로 생각하기’에서 박막·테스트·물류 예제로 바로 이동한다. 각 장의 URL은 공유할 수 있고 전체 읽기·인쇄·본문 및 계산값 검색을 지원한다. 기존 33개 장의 ID와 순서는 유지한다.

## 3차: 수식·범위·사용성 재검토

- 단계 수율의 조건부 비율 연결과, 독립 다이 확률의 반복 곱에 필요한 가정을 구분했다.
- 비트/바이트, nm/회, nm/분, 퍼센트와 퍼센트포인트, 표시 반올림을 독립 산술 검사로 확인한다.
- 불합격과 실제 불량, 자료 부재와 낮은 성능, 상관된 전후 변화와 원인 검증을 구분한다.
- 계산 입력과 모델 한계를 접힌 참고문 아래에 숨기지 않고 본문에 표시한다.
- 서재 편집일은 회사·품목·교과서 편집일과 실제 수집일 중 최근 날짜를 사용한다. 기업별 원문 확인일과 주간 수집 성공일을 바꾸지 않는다.

## 구현과 검증

`src/applied-reading.js`는 31개 품목의 보강 내용이고 `src/reading-core.js`가 기존 품목에 연결한다. `src/textbook-advanced.js`는 22개 장·33개 용어이며 `src/textbook-core.js`가 기존 교과서에 이어 붙인다. 두 자료는 브라우저와 Node.js에서 같은 내용으로 동작하고 중첩 객체까지 동결한다.

`npm run check`는 내용·링크·출처 상태·중복·산술·생성 인덱스를 검사한다. `npm run test:reading`은 31개 평가 기준·키보드로 펼친 사례·320px 화면·검색을, `npm run test:textbooks`는 55개 장·11개 예제·세 화면 너비·11개 전체 인쇄를 검사한다. 접근성 검사에는 모든 품목의 펼친 사례와 모든 계산 장을 포함한다.

새 본문은 기존 서재를 바탕으로 직접 작성한 교육용 설명이다. 외부 본문·그림을 복제하지 않았으며 새 원문 재열람 완료나 기업 사실의 검증 승격으로 표시하지 않는다. 기존 회사 45개 기록·46권 URL·사실 단위 대조 15건·신뢰도·원래 확인일과 학습 기록 형식을 유지한다.

로컬 검증에서 단위 검사 114개, 읽기 화면 371개, 교과서 화면 152개, 회사별 화면 431개, 기존 화면 회귀 152개가 통과했다. 접근성은 172개 화면·뷰포트에서 감지된 위반이 없었고, 이후 추가한 교과서 서가 바로가기 영역도 320px·1280px에서 별도로 검사했다. 외부 원문 재열람이나 운영 사이트 직접 점검을 대신하는 결과는 아니다.
