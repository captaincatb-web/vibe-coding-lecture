# 탐색 책갈피 백업과 복원

통합 탐색의 '탐색 책갈피와 최근 본 항목' 아래에서 백업 JSON을 다운로드하거나 복원한다. 탐색 책갈피만 포함하며 기존 책장 즐겨찾기와 별개다.

복원은 최대 1MB, 올바른 형식·버전과 최대 100개 문자열 키만 받는다. 현재 자료에 없는 키는 제외하고 중복을 제거해 기존 책갈피에 병합한다. 병합 결과가 100개를 넘거나 JSON/형식이 잘못되면 기존 값을 유지한다. localStorage 저장 실패를 안내하고 성공한 것처럼 표시하지 않는다. 백업 파일은 브라우저에서 처리하며 서버에 업로드하지 않는다.

`tests/silicon-bookmark-backup.js`에서 실제 브라우저로 병합·미등록 키 제외·잘못된 JSON 보존·다운로드를 검증한다. CI HTTP 서버 실행 단계에도 포함했다.
