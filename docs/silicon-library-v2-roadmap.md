## 배포와 PR 의존성
A의 base는 sharp-cannon이다. 기본 브랜치는 사이트 소스가 없어 이번 PR의 base로 적합하지 않다.
이 브랜치에는 배포 workflow를 추가하지 않는다. 병합은 Pages 실행을 유발할 수 있으므로 사용자 요청 없이 병합·배포하지 않는다.
#3과 A는 독립 검토한다. B의 데이터 기반은 A 위의 별도 브랜치에서 준비하며, #3의 현재 head에 대한 변환 호환성도 별도로 검사했다. 실제 화면 전환은 둘의 최종 통합 SHA에서 다시 검증한 뒤 진행한다.
후속 PR마다 변경 전후 화면, 출처/주장 변경, 자동 검사, 제한, 롤백을 포함한다.
