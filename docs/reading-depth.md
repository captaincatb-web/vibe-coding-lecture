# 책 내용 반복 개선 · 원리와 구분점

운영 버전 `1b4cd7b`에서 이어서, 46권의 사업·제품 및 핵심 기술 본문과 31개 품목별 해설을 보강했습니다.

## 설명 보강

모든 품목에 역할 설명, 입력·작용·평가를 따라가는 세 단계 흐름, 관련 품목과의 차이, 이해 확인 문답을 작성했습니다. 사업·제품 쪽에는 연결 품목별로 실제 제품 자료에서 확인할 질문을 추가했습니다. 책의 기존 목차 8개와 URL·즐겨찾기는 유지합니다.

주요 구분점은 PR과 PID의 잔류 역할, 전구체와 타겟의 원료 공급 방식, 프로브카드와 테스터의 접촉·시험 기능, 장비 부품 세정과 웨이퍼 세정, HBM 이형 필름과 접착·절연 재료, 벌크가스와 특수가스의 분류 기준 등입니다.

새 설명은 기존 `TX`·공정·심화 자료를 바탕으로 직접 작성한 **교육용 일반 원리**입니다. 개별 회사의 사양·고객 채택·매출을 새로 주장하거나 기업 사실의 검증 등급·확인일을 올리지 않았습니다. 이해 확인 문답은 펼쳐 읽는 설명이며, 기존 랩 퀴즈의 성적·완료 기록에는 포함하지 않습니다.

## 기존 표현 정정

| 대상 | 정정한 내용 |
| --- | --- |
| 전구체 정의 | 모든 전구체를 유기화합물로 한정하는 표현 정정 |
| 불화가스 정의·용도 | 불소 포함 여부와 식각·세정·텅스텐 증착의 역할 구분 |
| 식각가스 원리 | 재료·반응 조건의 차이를 설명하고 비교 근거가 없는 사용 비중 최상급 표현 제거 |
| 벌크가스 원리·트렌드 | 공기분리 설명을 수소에 일반화하지 않고, 모든 팹의 공급 설비가 같다는 표현 정정 |
| PR 정의·원리 | 고분자·화학증폭형을 모든 레지스트의 공통 원리로 읽지 않도록 정정 |
| 마스크 정의·원리 | 투과형·반사형을 구분하고 특정 축소 배율을 모든 노광기의 규격으로 읽지 않도록 정정 |

총 10개 필드의 이전 표현·새 표현·이유·기존 자료 위치를 `src/reading-core.js`에 기록했습니다. 이는 편집 정정 기록이며 새 원문 대조 완료 목록이 아닙니다. 기존 심화 자료의 정정 기록과 수치 미검증 목록은 별도로 보존합니다.

## 일관성과 검증

원본 품목 설명을 고친 뒤 정규화 데이터와 탐색 인덱스도 다시 생성했습니다. 확장 설명은 통합 탐색 및 책장 기술 백과 검색에 포함됩니다. 기업·품목·공정의 관계를 추가하거나 검증된 납품으로 바꾸지 않았습니다.

`npm run check`는 내용의 누락·잘못된 비교 대상·정정 전 표현의 재등장과 생성본 불일치를 검사합니다. `npm run test:reading`은 46권의 확장 본문과 31개 품목 페이지, 키보드 문답, 검색 연결을 검사합니다. 접근성 검사에는 독립 품목 페이지와 펼친 문답도 포함합니다.

이번 확인에서 ASML 및 Air Products 원문은 환경의 HTTP 403으로 접근하지 못했습니다. 새로운 원문 열람·검증을 주장하지 않으며, 기존 출처의 열람 상태와 확인일은 유지합니다. 로컬 브라우저 검사는 HTTP 서버·Chromium·시스템 폰트 fixture를 사용합니다.
