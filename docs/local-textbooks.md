# 서재 안에서 읽는 교과서

기업 책의 **함께 읽을 교과서**를 내부 개념 교과서와 연결했습니다. 공정 백과와 품목군에서 사용하는 같은 교과서 키도 내부 본문으로 이어집니다. 기존 외부 참고 링크는 별도로 유지합니다.

| 키 | 직접 작성한 교과서 | 구성 |
| --- | --- | --- |
| IND | 반도체 산업의 연결 | 역할, 품목·기업 연결, 근거 읽기 |
| FIL | 박막과 증착 | 막의 기능, ALD·CVD·PVD, 성장량과 피복성 |
| PLS | 플라즈마의 역할 | 반응종, 표면 작용, 장비 상태 |
| ETC | 식각과 형상 전사 | 선택비, 깊은 구조, 세정 대상 |
| LIT | 노광과 패턴 형성 | 패턴 전사, 광학 모델, 감광 재료 |
| CMP | 평탄화와 표면 관리 | 접촉·반응, 형상·결함, 상대 모델 |
| PRC | 반도체 제조 흐름 | 기판, 공정 반복, 세정·계측·피드백 |
| PKG | 패키징과 연결 | 기판·재배선, 적층, 열·신뢰성·검사 |
| TST | 테스트와 측정 | 검사 범위, 인터페이스, 조립 전후 시험 |
| MEM | 메모리의 구조 | 저장 방식, 용량·대역폭·지연, 서로 다른 적층 |
| FAB | 팹 인프라와 운영 | 공급, 수질·진공, 물류와 병목 |

각 교과서에 학습 목표, 다섯 개의 장, 핵심 용어 여섯 개를 넣었습니다. 총 55개 장은 기존 원리 33개 장과 2026.11.10에 추가한 계산 11개 장·종합 사례 11개 장으로 구성됩니다. 31개 품목이 교과서의 관련 품목에 모두 포함됩니다.

4장에서는 가상 입력·단위·가정·수식·계산 과정·한계를 함께 읽고, 5장에서는 여러 지표와 근거를 연결합니다. 기존 33개 장의 ID와 순서는 유지하므로 공유된 주소와 이전·다음 읽기를 보존합니다. 새 예제의 수치를 실제 회사 성능·양산 규격으로 제시하지 않습니다. [계산 예제와 품목별 평가 기준](applied-reading.md)

## 읽기와 공유

- 교과서 서가: `#textbooks`
- 본문 검색: `#textbooks?q=지연시간`
- 교과서 시작: `#textbook?book=FIL`
- 특정 장: `#textbook?book=FIL&chapter=methods`
- 전체 본문: `#textbook?book=FIL&chapter=all`

검색은 제목·본문·예시·계산값·가정·용어를 대상으로 합니다. 목차와 이전·다음 장은 공유 가능한 URL로 이동하고 키보드 포커스를 장 제목으로 옮깁니다. 전체 읽기는 교과서의 다섯 장을 한 화면에 표시하며, 인쇄는 현재 펼친 본문을 기준으로 합니다. 복습 문답은 설명을 펼쳐 보는 기능이며 기존 실습 퀴즈나 수동 학습 완료 기록을 변경하지 않습니다.

## 집필과 참고 범위

새 본문은 기존 서재의 공정·품목·심화 설명을 바탕으로 직접 집필한 교육용 일반 원리입니다. 외부 교과서의 본문·그림·코드를 복제하지 않았습니다. 예시는 사고를 돕는 상황이며 실제 제품 성능·고객 채택·양산 결과를 새로 검증한 자료가 아닙니다.

외부 교과서는 참고 링크로 구분하고 이번 원문 재열람 전임을 표시합니다. 교과서의 본문·표지·문답은 로컬 정적 파일로 제공하며 외부 교과서 사이트를 불러오지 않습니다. 외부 이미지나 새 런타임 의존성은 추가하지 않았습니다.

## 검증

`npm run check`는 11종·55개 장의 구성, 링크 대상, 문답, 비교 대상과 URL 처리, 11개 계산 예제의 산술·단위를 포함합니다. `npm run test:textbooks`는 55개 장과 11개 전체 읽기, 입력·가정·계산·한계 표시, 검색·공유·키보드·브라우저 뒤로가기·모바일·인쇄를 검사합니다. 외부 교과서 요청을 차단한 상태에서 내부 본문을 읽을 수 있는지도 확인합니다.

기업 책 46권의 내부 교과서 연결은 `npm run test:reading`, 기존 화면은 `npm run test:ui`, 교과서와 펼친 복습의 접근성은 `npm run test:a11y`에서 함께 검사합니다. 클라우드의 로컬 브라우저 검사는 HTTP 서버와 시스템 폰트 fixture를 사용합니다.
