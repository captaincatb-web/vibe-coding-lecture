# 기업 비교와 탐색·학습 정확성 개선

기준일 2026-11-08 KST. base는 통합 버전 21dbc89, 검토 브랜치는 `codex/silicon-library-v2-comparison`이다.

## 바뀐 사용 흐름

통합 탐색에서 기업을 선택하고 **기업 비교에 추가**를 누르면 최대 3곳을 나란히 볼 수 있다. 주/보조 분류, 자료 확보 등급, 공급망 구분과 판단 근거, 사업·법인 단위, 연결 품목과 공정, 기존 사실 대조 건수와 날짜, 참고자료 등록 범위를 비교한다. 표 안의 품목·공정도 기존 탐색으로 이어진다.
선택은 `#explore?...&compare=company%3Ac05%2Ccompany%3Ac22`처럼 공유 주소에 포함한다. 새로고침·뒤로가기에서도 복원된다. 기업별 제외·전체 비우기, 키보드 가로 스크롤, 모바일 화면과 인쇄 레이아웃을 지원한다. 비기업·중복·알 수 없는 ID는 비교에서 제외한다.

자료 확보 A/B/C는 사실 검증 상태가 아니다. 기업 레코드 수를 법인 수로 세지 않는다. 린데 2개 법인/사업 단위와 에이텍솔루션 2개 사업의 기존 구분을 유지한다. 미확인 국가는 추정하지 않고, 정규화되지 않은 재무 수치는 0으로 채우지 않는다. 이 표는 기업 우열·특정 고객 납품·경쟁관계를 판정하지 않는다.

## 수정한 문제

- `ALD/CVD`, `ALD·CVD`, 전각 영문/구분자 검색을 여러 검색어로 처리한다. `---`, `/`, `...`처럼 구분자만 있는 입력은 전체 항목이 나오는 대신 빈 결과를 반환한다.
- 검색 자료의 null 출처/주장, 중복 ID, 잘못된 배열·프로필, 타 기업의 사실 대조 연결을 검증 오류로 처리한다. 잘못된 응답이 검사기 내부 예외로 끝나는 문제를 수정했다.
- 공정 시퀀스에서 `식각 → 세정 → 재증착` 뒤에도 이전 패턴 표시가 남던 문제를 수정했다. 새 상부 막은 비패턴 상태에서 시작하고 다음 식각 후 패턴을 표시한다.
- `웨이퍼 → 계측 → 포토`처럼 이 교육 모델에서 박막 없이 패턴을 전사하는 순서를 거부한다. 가능한 다음 단계에도 해당 선택을 제시하지 않는다. 실제 FAB 레시피의 허용/금지 규칙을 주장하는 것은 아니다.

## 데이터와 검증

정규화 원본·DEEP·과거 사실 검증 상태는 바꾸지 않았다. 검색 인덱스에 기존 정규화 기업의 비교용 프로필만 추가했다. 기존 index version 1의 필드에 추가한 선택적 정보이며 프로필이 없는 기존 인덱스도 보수적으로 미확인으로 표시할 수 있다. 생성은 `npm run build`, 생성본 최신성 검사는 `npm run check`로 재현한다.

- Node 데이터/모델 검사 **63/63** 통과.
- 기업 비교 UI **19/19** 통과: 추가·상한·제외·전체 비우기·URL/뒤로가기 복원·모바일·키보드 스크롤·인쇄·잘못된 공유 입력·연결 탐색.
- 기존 탐색 **27/27**, 학습 랩 **33/33** 통과. 재증착과 두 번째 식각의 실제 SVG 상태도 확인한다.
- 기존 전체 UI 회귀 **152/152** 통과.
- 비교를 포함한 axe 검사 **14개 화면/뷰포트**, 자동 감지 위반 0건. 로컬은 시스템 글꼴 fixture이며 운영 네트워크·수동 스크린리더 검증과 구분한다.

```bash
npm ci --cache /tmp/showreel-npm-cache --no-audit --no-fund
npm run build
npm run check
python3 -m http.server 8767 --bind 127.0.0.1
```

다른 터미널에서:

```bash
SL_BROWSER_EXECUTABLE=/usr/bin/chromium SL_TEST_URL=http://127.0.0.1:8767/silicon-library/ SL_OFFLINE_FIXTURES=1 npm run test:comparison
```

기존 `test:ui`, `test:explorer`, `test:labs`, `test:a11y`도 같은 환경 변수로 실행한다. CI에 비교 UI 검사를 추가했다.
