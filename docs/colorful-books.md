# 책등이 보이는 책꽂이

기업 책 46권과 교과서 11종을 예전처럼 책등이 나란히 보이는 형태로 배치했습니다. 세로 제목, 높이·두께가 다른 책, 색상과 금박 띠, 나무 선반으로 책꽂이를 표현합니다. 품목군별 작은 문양을 책등 아래에 표시하며 긴 기업명도 장식과 겹치지 않도록 조정했습니다.

첫 화면 위의 덕산테코피아·TSE·와이씨 세 권도 선반 위에 세운 책등으로 보여 줍니다. 각 책은 실제 기업 책으로 연결됩니다. 소재·부품·장비 서가 바로가기는 주소를 바꾸지 않고 해당 제목으로 키보드 포커스와 화면을 이동합니다.

기업명·품목·기술·공정 검색과 신뢰도·즐겨찾기 필터를 유지하며, 결과가 없는 품목군·서가는 숨깁니다. 검색 결과가 없거나 즐겨찾기가 비어 있으면 안내를 표시합니다. 기존 46개 책 주소, 별칭, 데이터, 즐겨찾기 저장 키는 유지합니다. 표지의 자료 확보 상태와 상세한 검증 범위 설명도 계속 제공합니다.

좁은 화면에서는 책등을 선반 단위로 줄바꿈합니다. 검색·즐겨찾기 필터에서 숨긴 책의 자리도 함께 접습니다. 동작 줄이기 설정에서는 책을 꺼내는 전환을 줄입니다. 제목이 세로로 보이고 선반 위에서 잘리지 않는지, 검색 결과와 빈자리가 일치하는지, 키보드 이동과 320/390/768/1280px 배치를 `npm run test:shelf`로 검사합니다. 교과서는 `npm run test:textbooks`로 검사합니다.

책등 배치의 로컬 검사에서 책장 UI 28개, 교과서 UI 82개가 통과했고, axe는 32개 화면/뷰포트에서 위반이 없었습니다. 관리형 클라우드 검사는 HTTP 서버와 시스템 폰트 fixture를 사용하므로 외부 폰트 제공 상태를 검증하지 않습니다.
