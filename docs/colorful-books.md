# 첫 화면의 표지형 책장

46권을 표지가 보이는 입체 책으로 배치했습니다. 10가지 색상과 금박 느낌의 테두리, 종이 단면, 그림자로 질감을 표현하고, 기존 품목군의 기술 문양을 SVG로 그립니다. 각 책의 색상·문양은 새로고침 후에도 같습니다. 외부 이미지나 새 라이브러리는 추가하지 않았습니다.

첫 화면 위의 덕산테코피아·TSE·와이씨 세 권은 실제 기업 책으로 이동하는 소개용 선택입니다. 순위나 추천 투자 종목을 뜻하지 않습니다. 소재·부품·장비 서가 바로가기는 주소를 바꾸지 않고 해당 제목으로 키보드 포커스와 화면을 이동합니다.

기업명·품목·기술·공정 검색과 신뢰도·즐겨찾기 필터를 유지하며, 결과가 없는 품목군·서가는 숨깁니다. 검색 결과가 없거나 즐겨찾기가 비어 있으면 안내를 표시합니다. 기존 46개 책 주소, 별칭, 데이터, 즐겨찾기 저장 키는 유지합니다. 표지의 자료 확보 상태와 상세한 검증 범위 설명도 계속 제공합니다.

좁은 화면에는 두 열로 배치하고, 동작 줄이기 설정에서는 표지의 전환 효과를 줄입니다. 첫 화면에 대한 키보드·이동·검색·즐겨찾기와 320/390/768/1280px 배치 검사는 `npm run test:shelf`에서 실행합니다. 밝은 모드·어두운 모드의 첫 화면은 `npm run test:a11y`에도 포함됩니다.

로컬 검증: 데이터 검사와 Node 73개, 기존 UI 152개, 책장 UI 24개 통과. axe는 첫 화면과 책·학습·탐색 화면을 포함한 22개 화면/뷰포트에서 위반이 없었습니다. 관리형 클라우드 검사는 HTTP 서버와 시스템 폰트 fixture를 사용했으므로 외부 폰트 제공 상태를 검증하지 않습니다.
