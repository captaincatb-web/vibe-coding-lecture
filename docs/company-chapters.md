# 회사별 해설과 품목별 비교

2026.11.09 전구체 5개사의 공통 설명 반복을 줄인 뒤, 2026.11.10 나머지 40개 기록에도 회사별 내용을 작성했다. 현재 45개 회사 기록에 해설 135개·학습 사례 45개·제품과 사업 카드 128개를 연결한다. 기존 46권 중 에이텍솔루션의 두 번째 사업은 같은 회사 기록으로 유지한다. 회사 기록의 수를 법인 수로 간주하지 않는다.

## 읽기 흐름

표지의 소개와 소재 태그부터 회사별 중심축·제품군으로 구분한다. 기업 개요에는 회사별 중심축과 ‘이 회사의 기술장 읽기’를 둔다. 사업·제품 페이지는 소재군별 역할·확인할 차이·등록 근거를 먼저 보여 준다. 핵심 기술 페이지는 회사별 해설과 사례가 먼저 나오고, 공통 원리는 접힌 보충 자료로 남긴다. 기존 46개 책 주소와 8개 목차, 교과서·학습 랩 연결을 유지한다.

`#x-pre`의 비교표는 공통 원리 앞에서 5개사의 제품·기술·사업·첫 질문을 나란히 보여 준다. 좁은 화면에서는 표 안에서 좌우로 움직이며 회사 이름을 고정해 읽는다. 각 회사의 책으로 연결되고, 새 본문은 책장 검색과 통합 탐색에서도 찾을 수 있다.

품목 기술 페이지는 연결된 기록이 둘 이상이면 자동으로 비교표를 보여 준다. 각 책의 비교 링크도 해당 회사의 실제 연결 품목으로 구성한다. 비교표는 회사의 전체 읽기 중심축과 인접 사업을 포함하므로 제품별 승인·성능 비교표로 표시하지 않는다.

## 자료 범위

추가 해설은 `src/company-core.js`와 `src/company-supplements.js`에 회사 레코드 ID로 연결한다. 지분 관계가 있는 디엔에프와 솔브레인도 별도 레코드로 유지한다. 제품 카드와 각 해설에 기존 출처 ID를 연결하고 본문에서 등록 자료 링크를 표시한다. 원문을 새로 열람·대조했다는 뜻은 아니며, 검증 등급과 사실별 확인일은 바꾸지 않았다. 학습 사례는 실제 회사의 불량·실적을 재현한 사례와 구분해 가정으로 작성했다.

와이컴·GT는 등록된 회사·제품 원문이 없어 목록 표기와 확인 과제를 구분하며, 제품·고객·납품·성능을 만들어 넣지 않는다. 비교표에도 ‘제품 근거 확인 전’을 표시한다. AMMK는 확인된 PTFE 사업과 목록의 HBM 적용 추정을 분리한다. 재료 카드 수는 자료에 맞게 1~3개로 두며 출처 없는 기록을 임의의 세 제품으로 채우지 않는다.

기존 문장의 네 곳도 바로잡았다. DIPAS를 모든 DPT 방식의 필수 원료로 읽는 표현, 디엔에프의 제품 구성을 완전한 사업 전환으로 읽는 요약, 비교 근거 없는 솔브레인 규모 순위, 몰리브덴 원소와 개별 전구체의 공급 상태·운전 조건을 혼동하는 표현이다. 생성 데이터와 탐색 색인도 함께 갱신한다.

## 확인

`npm run check`에 회사 레코드·제품·출처 연결, 내용 중복, 잘못된 표현의 재발, 검색, 검증 상태 보존 검사를 포함한다. `npm run test:companies`는 회사별 본문·제품 카드·사례·출처·접힌 공통 원리·키보드·검색·비교표·모바일을 검사한다. 기존 읽기 검사도 공통 원리를 펼쳐 읽는 흐름에 맞추어 원자층 성장·노출량·미검증 수치 안내가 남아 있는지 확인한다. 접근성 검사는 전구체 5개사와 NCK·에이텍솔루션·린데·와이컴·GT의 사례·출처·공통 원리를 펼친 상태와 여러 품목의 비교표를 포함한다.

2.9 로컬 검증에서는 데이터·단위 검사 110개, 회사별 화면 431개, 기존 읽기 276개가 통과했고 접근성은 100개 화면·뷰포트에서 감지된 위반이 없었다. 모든 45개 기록과 자료 미확인 분기를 포함하도록 확대했다. 외부 자료의 이번 원문 재열람이나 운영 사이트 직접 점검을 대신하는 검사는 아니다.
