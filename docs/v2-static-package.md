# 정적 검토 패키지

`silicon-library-v2-review.zip`은 빌드가 끝난 정적 사이트와 검토 문서·화면을 담는다. npm 의존성·Git 메타데이터·자격증명은 포함하지 않는다.

압축을 푼 폴더에서 다음 명령으로 HTTP 서버를 실행한다.

```bash
python3 -m http.server 8767 --bind 127.0.0.1
```

브라우저에서 해당 서버의 `/silicon-library/` 경로를 연다. 탐색 데이터는 HTTP로 읽으므로 HTML 파일을 더블클릭해 여는 file:// 방식은 지원하지 않는다. 정적 호스팅에는 `silicon-library/` 전체를 올려 상대 경로를 유지한다.

이 패키지 생성은 운영 배포가 아니다. 원본 개발 코드와 고정 의존성·테스트·CI는 Git 저장소의 검토 브랜치에 있다. 게시 전 PR #3·#4 및 통합 버전의 최종 병합 순서와 새 네트워크 설정을 확인한다.
