## 검증·재사용 규칙
URL 접근 성공 ≠ 원문 대조 완료 ≠ 재배포 허가. 기존 188개 출처도 이번에 모두 검증하지 않았다.
신규 사실에는 제목·발행 주체·URL·발행일·접근일·원문 위치·자료 유형·범위·단위·기간·검증 상태·한계를 연결한다.
기업 주장, 독립 검증, 전망, 편집 분석, 교육용 모델은 구별한다. 스니펫만으로 verified를 부여하지 않는다.
무료 열람 가능 여부와 공개 JSON 재배포 권한을 분리한다. 미확인 수치는 null/unverified이며 0으로 대체하지 않는다.
네트워크 실패는 retrieval_status=blocked로 기록하고 기존 정상 데이터를 삭제하지 않는다.
ETO의 자동 수집, 유료 보고서 전문, 비밀키의 브라우저 전송은 구현하지 않는다.

## 이번 네트워크 관측
Git HTTPS와 github.com 공개 PR·Actions·공개 트리는 읽을 수 있었다.
api.github.com 및 captaincatb-web.github.io는 403으로 차단됐다. Pages 설정과 운영 HTML/콘솔은 미확인이다.
로컬 UI 실행 중 fonts.googleapis.com 요청 실패가 확인됐다. 원문·라이선스와 무관한 환경 연결 문제로 별도 기록한다.
