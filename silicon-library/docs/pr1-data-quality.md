## 4. 분류 변경 기록(삼화전기)
- 근거: 회사 IR(2024.06), 한국IR협의회 리포트(2024.09), 리서치(2026.04)에서 제품은 eSSD용 S-CAP, 전해 커패시터, 하이브리드·EDLC. 제조공정 투입으로 설명한 대목은 찾지 못함(f013, 확인 불가).
- 판단(f015)은 편집 분석이며 "부분 검증"이다. 제조공정 투입 근거가 확인되면 재분류한다.

## 5. 분류 규칙
공급망 구분은 기존 공정 지도(제품→공정 연결)에서 계산한 값이며 새로 조사해 판정한 것이 아니다. 직접=인프라 외 공정에 연결, 간접=인프라 단계에만 연결, 관련 산업=제조공정과 무관한 반도체 제품·서버용 부품, 검증 필요=신뢰도 C. 이 규칙 때문에 에드워드(진공펌프)·세메스(물류)는 "간접"으로 표시된다. 이 표현이 적절한지는 후속 PR에서 검토한다.
