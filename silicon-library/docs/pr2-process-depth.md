# 실리콘 서재 PR2 — 반도체 공정·기술 콘텐츠 심화

작성 기준일 2026-11-02. 기준 커밋 `1424ab9`(PR1 머지). 진단은 `pr2-content-diagnosis.md`.

## 1. 범위
5개 기술 영역만 심화했다: 증착(ALD·CVD·PVD), 식각 및 세정, CMP, HBM 및 첨단 패키징, 반도체 테스트. 나머지 공정·제품 기술 본문은 바꾸지 않았다. 기존 해설과 출처는 삭제하지 않았고, 심화 해설은 각 공정 페이지의 기존 내용 아래에 덧붙는다.

## 2. 구성 (영역마다 같은 7개 관점)

## 3. 근거 원칙 (원문 대조 후 갱신)
- 신규 출처 36건의 열람 상태: **원문 열람 10건**(문서 전문을 가져와 해당 절을 직접 확인: JESD235D, JEDEC HBM4 보도자료, SK hynix IEDM 2023 논문, Electronics 2025 하이브리드 본딩 리뷰, SK hynix ISSCC 2018 논문, IEEE HIR 2024 테스트 장, IEEE EPS 테스트 BKM, Fischer 외 열 ALE 리뷰, Mo/Cu CMP 논문, 광대역 갭 프로브카드 리뷰), **원문 일부 열람 5건**(원문의 해당 절만 확인: Cremers 외 ALD 균일 피복 리뷰, Mattinen 외 MoS₂ ALD, ALE 리뷰(Springer), ECS 세정 논문집 PV 94-07, MIT 학위논문 5장), **검색 발췌 열람 21건**(검색 도구의 발췌만 확인). "미열람"으로 쓴 출처는 없다.
- 문장마다 검증 상태를 따로 표시한다(원문 확인·발췌 확인·미확인). 출처가 등록돼 있다는 사실만으로 문장이 검증된 것으로 처리하지 않으며, 표시가 없는 출처 연결 문장은 "출처 등록 · 문장 대조 전"으로 보인다.
- 정량 문장에는 유형(원논문 실험·리뷰 재인용·시뮬레이션·특허 실시예·기업 발표·일반화 가능 사실·논문 서술), 비교 대상, 조건·범위, 발행연도, 한계, 원 자료 열람 여부를 붙였다. 자세한 표는 `pr2-verification.md`.
- 리뷰가 재인용한 값은 "리뷰 재인용"으로 표시하고 인용 원 논문을 열람하지 않았음을 적었다. 시뮬레이션 값과 실험 값, 회사 발표와 제3자 검증을 구분했다.
- 수치 문장이 출처 없는 일반 원리로 통과하지 못하며, "불확실" 표시만으로 출처 없는 정량 주장이 통과하지 못한다(검증기 규칙).
- 고객사·공급 관계·점유율은 서술하지 않았고, 기업 연결은 품목 단위라는 안내를 공정·제품 페이지에 유지했다.
- 기업 신뢰도 A/B/C와 이 콘텐츠의 출처 상태는 별개다.

### 3.1 원문 대조에서 발견해 바로잡은 것
- **저자 오기**: ISSCC 2018 HBM2 논문은 Samsung이 아니라 SK hynix 논문이다(특허 심판 증거 사본의 사건명에서 혼동). 출처 제목과 본문을 정정했다. IEDM 2023 논문의 제목 표기도 바로잡았다.
- **디싱 0.65배**: 한 실험 안의 결과가 아니라 MIT 학위논문의 pH 7 중성 슬러리 실험과 문헌(Park 외 1999)의 화학 슬러리 비교이며, 폭 100μm 넓은 Cu에서만 나타나고 25μm 미만에서는 영향이 없다. 조건과 한계를 본문에 명시했다.
- **RIE lag 11.9nm→1.3nm**: ALE 일반이 아니라 7nm 노드 로직 low-k 식각에서 연속파 대 준-ALE(QALE)를 비교한 사례를 리뷰가 재인용한 것이다. 원 논문은 미열람.
- **SC1 입자 제거 0.80~0.90**: 1990년대 실험(70℃, 혼합비 3종, HF-last 오염 웨이퍼, 입자 >0.5μm)이며 현재 양산 성능으로 일반화하지 않는다.
- **열저항 47%·20%**: 리뷰가 22.8~47% 범위로 정리한 값의 상한은 Mehta 외 열 시뮬레이션 인용이고, 약 20%는 ECTC 2023 사례(시뮬레이션/측정 여부 불명)로 비교 대상이 다르다.
- **ALD 온도 100~400℃**: 한 논문 서론의 일반 서술일 뿐이며, 그 논문 자체 공정은 자기제한 구간이 250~325℃였다. 보장 범위처럼 쓰지 않았다.
- **ALD 균일 피복**: 같은 TMA/H₂O 공정도 피복 가능 종횡비가 5:1~1750:1로 보고돼 조건에 따라 다르며, 오존·플라즈마 ALD는 더 낮다. 자기제한이 모든 조건의 균일 피복을 보장한다고 쓰지 않았다.
- **HBM 수율 거듭제곱식**: 논문 도입부의 단순 모델이다. 독립성·전수 정상·수리 미반영 가정을 명시하고 양산 수율 예측식이 아님을 적었다.
- **HBM4 속도**: SK hynix 2023 논문의 "12Gbps 이상 요구"와 JEDEC 2025 보도자료의 "최대 8Gb/s"가 달라 불확실성으로 기록했다.
- **CVD 표현**: "CVD는 공급량 지배"로만 쓰지 않고 반응 율속과 물질 전달 율속 영역을 구분했다.

### 3.2 기존 해설의 수정과 미검증 표시
- 수정한 기존 문장 2개: 전구체 해설의 "한 사이클에 원자 1층(약 0.1nm)…깊은 홈 안쪽까지 균일"과 증착 공정의 "원자층 단위로 쌓음. 깊은 홈도 균일". 정정 전후 문장은 `deep-content.json`의 `corrections`에 보존하며 검증기가 되돌려지지 않았는지 확인한다.
- 출처 없는 기존 수치 32개(99.9999%(6N), 250℃, 1,000℃ 등)는 삭제하지 않고 **미검증**으로 표시해 공정·제품 페이지의 "수치 검증 상태"에 나열한다. 일반 기준값처럼 읽히지 않게 했다. 새 수치가 미검증 표시 없이 추가되면 검증기가 오류로 처리한다.
- `clean` 제품 기술(장비 부품 세정·코팅)과 웨이퍼 세정 공정의 연결은 구조를 바꾸지 않고(에이텍솔루션·한솔아이원스 연결 보존) 세정 공정 페이지와 제품 페이지에 두 기술의 차이를 명시했다. 구조 분리는 후속 과제.

## 4. 구체적으로 깊어진 설명 (예)
- 증착: 자기제한 표면 반응, 사이클별 증착, 포화 확인(도즈·퍼지 시간 대비 GPC), conformality와 step coverage 정의, CVD(flux 지배)와 ALD(표면 반응 지배)·PVD(직진성)의 차이, 전구체 요건과 반응성-열안정성 교환, 기생 CVD에 의한 seam·void. **기존 "사이클당 원자 1층" 설명의 단순화를 근거와 함께 정정**.
- 식각·세정: 이방성 정의식, 고종횡비 목표, ARDE 기구(중성종 수송), 가스 조성과 마스크 선택비·SiO₂/SiN 선택성, ALE(열/방향성), SC1 입자 제거가 식각 깊이에 의존한다는 실험, DHF 후 소수성 표면의 입자 부착.
- CMP: Preston 식과 한계, 금속 CMP의 부동태막 형성 기구, Cu/배리어 선택비와 디싱 방향, 디싱·에로전 정의(하이브리드 본딩 문맥 포함), 스크래치 발생원(입자·패드·브러시), 3단계 CMP의 소모품 증가.
- HBM·패키징: JEDEC HBM 표준 구조, HBM4 요약, TSV 흐름과 ALD 연결, TC-NCF/MR-MUF/하이브리드 본딩 비교, 수율이 TSV 수의 거듭제곱으로 곱해지는 구조, 12단 이상 열 축적, 검사 난이도(KGD·KGSD).
- 테스트: 프로브카드 종류와 역할, 터치다운·병렬도, 웨이퍼 레벨 번인, HBM 테스트 패드·DFT, 칩렛에서 프로브 피치와 패키징 피치의 분리.

## 5. 코드·데이터 변경
- 데이터: `silicon-library/data/deep-content.json`(원본) → `node scripts/build-deep.js`로 `index.html`의 DEEP 블록에 주입.
- 화면: 공정 페이지에 심화 해설 블록, 보조 공정(세정·패키징)에서 링크 카드, 기술 백과 목록·제품 기술 페이지에서 링크, 통합 검색에 심화 본문 포함. 기존 URL·내부 링크·책장·공정 지도는 그대로.
- 검사: `scripts/validate-silicon-library.js`에 DEEP 검사 추가(7개 관점 순서, 출처 ID, 수치 문장 출처, 전망 출처, 미열람 출처만으로 근거 표시, 열람 상태 값, 발행일/열람일, JSON과 주입 블록의 일치). 부정 테스트 6종 추가. PR1의 데이터 검사·CI는 그대로 유지.

## 6. 해결되지 않은 기술적 불확실성
- 36개 출처 중 21건은 검색 발췌만 확인했고, 원문 열람 10건과 일부 열람 5건도 해당 절만 본 것이다. 리뷰가 재인용한 수치(디싱 0.65배의 문헌 비교, 열저항 47%·20%, RIE lag 11.9→1.3nm)는 인용 원 논문을 열람하지 않았다. 유료 본문(ASME CMP 리뷰, 일부 특허 PDF)은 열람하지 못했다.
- HBM3·HBM3E 표준 원문 미열람, HBM4는 보도자료 요약만 확인.
- MR-MUF와 TC-NCF의 수율·열 성능 우열, 하이브리드 본딩의 HBM 양산 시점은 제3자 검증 자료를 확보하지 못했다.
- 챔버 소모 부품(Si·SiC·쿼츠·FFKM)의 마모·파티클, 패드 수명·컨디셔닝, 핸들러·소켓·번인의 정량 근거는 확보하지 못해 일반 원리로만 적었다.
- 프로브카드 피치(약 40μm)는 특허 실시예이며 업계 표준값이 아니다.
- 일부 출처는 오래됐다(세정 1994·2001년 학회 논문집). 현재 양산 조건과 다를 수 있음을 출처 목록에 표시했다.
- 기존 해설의 출처 없는 수치(진단 문서 2절)는 그대로 남아 있다.
